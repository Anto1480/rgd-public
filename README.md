# RGD documentation

RGD (**Replicated Godot**) is a multiplayer addon for Godot 4, heavily inspired by Roblox's multiplayer architecture.

| Read this | When |
|---|---|
| [Beginner's Guide](beginners_guide.md) | New to multiplayer or to RGD? Build a 2D platformer you can play alone or together, step by step, then export it and put it on GitHub. |
| [The RGD guide](guide.md) | From install to a working multiplayer game, one idea at a time; every concept in depth. |
| [Recipes](recipes.md) | Copy-paste features: coins, scoreboard, chat, round timer, health, shooting, teams, teleporters, private messages, physics objects. |
| [Godot features in RGD](godot_features.md) | How autoloads, shaders, animation, particles, physics, input, signals and resources behave when replicated. |
| [API reference](api.md) | A Godot-style class reference: every class with its properties, methods, signals and constants, plus settings, groups and command-line options. (Also in Godot's built-in help: press F1 and search for `Player`, `RemoteEvent`...) |
| [RGD for Roblox developers](roblox_guide.md) | Roblox → RGD name mapping and what's different. |
| [Sample 1: Flying Lobby](../samples/flying_lobby/README.md) | A small complete game: name entry, one player hosts, flying cubes with name + HP tags, damage decided by the host. |
| [Sample 2: Chat](../samples/chat/README.md) | A chat room with no characters, and the limitations found building it (with workarounds). |
| [Sample 3: Blaster Arena](../samples/shooter/README.md) | A 3D shooter on a dedicated server, and the engine problems it found (with before/after numbers). |
| [Sample 4: Coin Run](../samples/2d%20platformer/README.md) | A 2D platformer playable in single player or multiplayer with the same code. The Beginner's Guide builds it. |
| [Implementation plan](../Claude_Implementation.md) | Design decisions, wire protocol, milestones, benchmarks. For contributors. |
